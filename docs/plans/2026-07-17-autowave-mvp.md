# AutoWave MVP Implementation Plan

> **For agentic workers:** This plan is executed by the Claude↔Codex protocol in
> `CLAUDE.md`: Claude dispatches one task at a time to Codex
> (`codex:codex-rescue`, `--model gpt-5.6-luna --effort xhigh --write`), reviews
> the diff, runs the build gate, and commits. Codex reads `AGENTS.md` for
> conventions. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iOS rhythm game that converts a local audio file into a playable,
five-difficulty beatmap with a unique "wave ripple" visual identity.

**Architecture:** SwiftUI app shell (Library → Import → Analysis → Gameplay)
with a SpriteKit landscape gameplay scene. A pure-Swift `BeatmapKit` module
analyzes audio offline (vDSP FFT → spectral-flux onsets → tempo + per-onset
timbre features) and deterministically generates beatmaps per difficulty.
SwiftData persists tracks, beatmaps, and scores.

**Tech Stack:** Swift 6, SwiftUI, SpriteKit, SwiftData, AVFoundation,
Accelerate (vDSP), XcodeGen. Zero third-party dependencies.

## Global Constraints

- iOS deployment target: 17.0. Xcode 26.6, project generated by XcodeGen from `project.yml`; generated `AutoWave.xcodeproj` is committed.
- Build gate (every task): `env DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project AutoWave.xcodeproj -scheme AutoWave -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build`
- Difficulties, exact order/naming: 천국 (heaven), 쉬움 (easy), 보통 (normal), 어려움 (hard), 지옥 (hell).
- Audio input: local files only (fileImporter). YouTube ingestion out of scope (App Store 5.2.3 + YouTube ToS).
- `BeatmapKit` is deterministic (seeded), imports no UI frameworks, and is unit-tested.
- User-facing strings Korean; identifiers/comments English.
- Note visual identity: "wave ripple" system (below) — no capsule/arrow clones of existing rhythm games.
- Gameplay is landscape-only; 4 lanes.

## Visual identity: "wave ripple" notes

- **Tap note ("물방울", droplet):** a filled core dot with two concentric
  animated rings; the outer ring slowly contracts as the note approaches the
  hit line, reaching the core exactly at hit time (the ring IS the timing
  guide). On hit: expanding ripple splash + particles.
- **Drag note ("물결", wave ribbon):** a translucent undulating band whose
  spine follows the lane path (straight, or lateral bezier for moving drags).
  A glowing crest dot rides the spine under the player's finger; broken drags
  freeze grey with no further crest glow.
- **Palette:** derived from analysis (`ThemePalette`): bass-dominant → deep
  indigo/violet, mid-dominant → teal/cyan, treble-dominant → amber/coral;
  background is a slow audio-reactive ripple field of the same hue family.

### Task 5: Beatmap generation (5 difficulties, deterministic, diverse)

**Files:**
- Create: `AutoWave/Core/BeatmapKit/BeatmapGenerator.swift`
- Create: `AutoWave/Core/BeatmapKit/DifficultyProfile.swift`
- Test: `AutoWaveTests/BeatmapGeneratorTests.swift`

**Interfaces:**
```swift
struct DifficultyProfile: Sendable {
    var maxNotesPerSecond: Double   // heaven 0.8, easy 1.5, normal 2.5, hard 4.0, hell 6.0
    var strengthPercentile: Double  // keep onsets above: 85, 65, 45, 25, 10
    var maxSimultaneous: Int        // 1, 1, 1, 2, 2
    var dragRatio: Double           // fraction of eligible onsets becoming drags: 0.10, 0.15, 0.20, 0.25, 0.30
    var movingDragRatio: Double     // of drags, fraction with lanePath: 0, 0.2, 0.4, 0.6, 0.8
    var scrollSpeed: Double         // px/s hint for scene: 250, 320, 400, 500, 620
    static func profile(for: Difficulty) -> DifficultyProfile
}
enum BeatmapGenerator {
    static let version = 1
    static func generate(from analysis: AnalysisResult, difficulty: Difficulty, seed: UInt64) -> Beatmap
}
```
- Generation rules (deterministic, seeded `SplitMix64`-style RNG): lane from
  quantized spectral centroid (low→lane 0 … high→lane 3) with seeded jitter to
  avoid streaks; drags start where ≥0.8 s of sustained inter-onset energy
  exists, duration snapped to beat grid, moving drags get 2–3 `LaneKeyframe`s
  within ±1 lane; enforce per-profile density by strength-ranked culling;
  palette from mean band ratios (bass→hue 0.72, mid→0.5, treble→0.08,
  interpolated by dominance; saturation 0.55–0.8 from spread; brightness
  0.5–0.75 from meanRMS).

**Steps:**
- [ ] Codex: tests FIRST: determinism (same input+seed ⇒ byte-identical JSON), density ordering (heaven < easy < normal < hard < hell note counts on same analysis), no overlapping notes in one lane, drag durations > 0, hell contains moving drags on a synthetic busy track. Then implement.
- [ ] Claude: review; build gate; tests pass.
- [ ] Claude: commit `feat: add deterministic five-difficulty beatmap generator`.
