# AutoWave 수동 테스트 체크리스트

자동 테스트(유닛 30+개)가 못 보는 것들: 실제 음원 품질, 게임 손맛, 프레임, 햅틱.
시뮬레이터로 대부분 확인 가능하지만 **햅틱·성능·오디오 지연은 실기기 필수**.

## 0. 빌드 & 실행

- [ ] Xcode 26에서 `AutoWave.xcodeproj` 열기 → iPhone 시뮬레이터 선택 → Run: 빌드 에러/워닝 없이 실행
- [ ] 실기기 실행 시: 서명(Team) 설정만으로 설치 가능
- [ ] 앱 아이콘이 홈 화면에 정상 표시 (리플 링 + 물방울 디자인)

## 1. 라이브러리 (빈 상태)

- [ ] 첫 실행: "라이브러리가 비어 있어요" + 물결 아이콘 + "음원 가져오기" 버튼 표시
- [ ] 앱 재실행해도 크래시 없음 (SwiftData 스토어 생성 확인)

## 2. 음원 가져오기

- [ ] "음원 가져오기" → Files 픽커 열림, 오디오 파일만 선택 가능
- [ ] **mp3 / m4a / wav 각 1개씩** 가져오기 성공, 라이브러리에 제목·길이 표시
- [ ] 같은 파일 두 번 가져오기: 항목 2개 생성 (중복 허용), 크래시 없음
- [ ] iCloud Drive에 있는 (기기에 미다운로드) 파일 선택 시 동작 확인
- [ ] 손상/비정상 파일 (예: 확장자만 mp3인 텍스트): 한국어 에러 메시지, 크래시 없음

## 3. 변환 (분석)

- [ ] 트랙 탭 → 변환 화면 자동 시작: "분석 중…" 진행률 → "비트맵 생성 중… (n/5)" → "완료!"
- [ ] 리플 애니메이션 자연스러움, 진행률 후퇴 없음
- [ ] **3–4분 곡** 변환 소요 시간 체감 (수십 초 이내 기대) — 오래 걸리면 보고
- [ ] 완료 후 라이브러리에 난이도 뱃지 5개 (천국/쉬움/보통/어려움/지옥) 표시
- [ ] 같은 트랙 재변환: 뱃지 5개 유지 (중복 생성 없음)
- [ ] 변환 중 화면 이탈/앱 종료 후 재시도: 정상 동작

## 4. 난이도 선택

- [ ] 변환된 트랙 탭 → 픽커에 5난이도 + 태그라인 + 색상 (천국 하늘색 … 지옥 빨강)
- [ ] 각 난이도 선택 시 게임 진입

## 5. 게임플레이 — 핵심 손맛 ★

곡 하나로 **보통** 먼저, 그다음 **천국**과 **지옥**.

- [ ] 진입 시 가로 화면 강제 + 0.8초 색 워시인 (곡 분위기에 맞는 색인지: 베이스 강한 곡 → 남보라, 밝은 곡 → 청록/호박)
- [ ] 노트가 **박자에 맞게** 내려옴 — 히트라인 도달 시점 = 실제 비트 (어긋나면 몇 ms 정도인지 체감 보고)
- [ ] 물방울 노트: 수축 링이 히트 순간 코어와 정확히 겹침 (타이밍 가이드 역할)
- [ ] 탭 판정: 정타 PERFECT, 살짝 어긋나면 GREAT/GOOD, 무시하면 MISS + 콤보 리셋
- [ ] 판정 표시 + 콤보 카운트 가독성 (배경 리플과 겹쳐도 읽힘)
- [ ] 드래그 리본: 누르고 유지 → 점수 틱 계속 증가; 이동 리본은 손가락 따라 좌우 추적 가능
- [ ] **드래그 중간에 손 뗌/이탈 → 남은 리본 회색화 + 그 이후 점수 없음 + 콤보 리셋** (핵심 규칙)
- [ ] 배경 리플 필드가 음악에 반응 (베이스 킥에 링 팽창)
- [ ] 천국: 한숨 돌릴 만큼 널널 / 지옥: 벅찰 만큼 빽빽 + 2레인 동시노트 + 이동 드래그 다수 — 난이도 격차 체감
- [ ] (실기기) 햅틱: PERFECT 묵직, GREAT/GOOD 가벼움, 드래그 브레이크 경고 진동
- [ ] (실기기) 3–4분 곡 풀플레이 중 프레임 드랍/발열/오디오 끊김 없음

## 6. 일시정지 / 중단

- [ ] 일시정지 버튼 → 음악+노트 즉시 정지, 오버레이 (계속하기/다시하기/나가기)
- [ ] 계속하기 → 3-2-1 카운트다운 후 **정확히 멈춘 지점부터** 재개 (판정 어긋남 없어야 함)
- [ ] 홈으로 나갔다 복귀 → 자동 일시정지 상태
- [ ] 플레이 중 전화/알람 수신 (실기기) → 자동 일시정지, 복귀 정상
- [ ] 다시하기 → 처음부터 재시작; 나가기 → 라이브러리 복귀 + 세로 화면 복원

## 7. 결과 화면

- [ ] 곡 종료 → 점수, 최대 콤보, 판정 집계 (퍼펙트/그레이트/굿/미스) 표시
- [ ] 합계 검산: 판정 수 합 = 총 노트 수 (드래그는 헤드 1개 기준)
- [ ] "다시하기" / "라이브러리" 버튼 동작
- [ ] 같은 난이도 재플레이 후 점수 기록 유지 (ScoreRecord 저장)

## 8. 삭제 & 데이터

- [ ] 라이브러리 스와이프 삭제 → 항목 + 비트맵 + 점수 사라짐, 크래시 없음 (cascade 확인)
- [ ] 삭제 후 앱 재시작: 삭제 상태 유지
- [ ] 트랙 여러 개 (5개+) 상태에서 목록 스크롤/뱃지/팔레트 액센트 정상

## 9. 엣지 케이스

- [ ] 아주 짧은 음원 (10초 미만): 변환/플레이 정상 or 합리적 처리
- [ ] 조용한 곡 (어쿠스틱/피아노): 노트가 너무 적거나 이상하지 않은지
- [ ] 무음 구간 긴 곡: 무음 구간에 노트 없음
- [ ] 저장공간 여유 없는 기기 (선택): 가져오기 실패 시 에러 메시지

---

**보고 요령**: 실패 항목은 `곡 이름 + 난이도 + 증상 + (가능하면) 타이밍 어긋남 방향(빠름/느림)`.
판정 윈도우(±50/100/150ms)·스크롤 속도·난이도 밀도는 전부 상수로 모여 있어
(`JudgmentEngine.swift`, `DifficultyProfile.swift`) 체감 기반 튜닝 즉시 가능.
