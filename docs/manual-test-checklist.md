# AutoWave 수동 테스트 체크리스트

자동 테스트(유닛 50+개)가 못 보는 것들: 실제 음원 품질, 게임 손맛, 프레임, 햅틱.
시뮬레이터로 대부분 확인 가능하지만 **햅틱·성능·오디오 지연은 실기기 필수**.

디자인 기준: `docs/design/styleguide.html` (네온 스페이스). 화면이 스타일가이드와
다르면 보고.

## 0. 빌드 & 실행

- [ ] Xcode 26에서 `AutoWave.xcodeproj` 열기 → iPhone 시뮬레이터 선택 → Run: 빌드 에러/워닝 없이 실행
- [ ] 실기기 실행 시: 서명(Team) 설정만으로 설치 가능
- [ ] 앱은 가로 화면 고정 (세로 회전 안 됨)
- [ ] 앱 아이콘이 홈 화면에 정상 표시

## 1. 곡 선택 (빈 상태)

- [ ] 첫 실행: 곡이 없으면 중앙에 점선 네온 "음원 파일 선택" 카드 표시
- [ ] 좌상단 PLAYER 배지, 우상단 원형 `+`(가져오기) 버튼 표시
- [ ] 앱 재실행해도 크래시 없음 (SwiftData 스토어 생성 확인)

## 2. 음원 가져오기

- [ ] 우상단 `+` → Files 픽커 열림, 오디오 파일만 선택 가능
- [ ] **mp3 / m4a / wav 각 1개씩** 가져오기 성공, 곡 선택 캐러셀에 제목·길이 표시
- [ ] 같은 파일 두 번 가져오기: 항목 2개 생성 (중복 허용), 크래시 없음
- [ ] iCloud Drive에 있는 (기기에 미다운로드) 파일 선택 시 동작 확인
- [ ] 손상/비정상 파일 (예: 확장자만 mp3인 텍스트): 한국어 에러 메시지, 크래시 없음

## 3. 변환 (분석)

- [ ] 곡 가져오면 변환 화면 자동 시작: "분석 중…" 진행률 → "비트맵 생성 중…" → "완료!"
- [ ] 리플 애니메이션 자연스러움, 진행률 후퇴 없음
- [ ] **3–4분 곡** 변환 소요 시간 체감 (수십 초 이내 기대) — 오래 걸리면 보고
- [ ] 완료 후 곡 선택 디스크에 최고 난이도 라벨(예: HARD) 표시
- [ ] 같은 트랙 재변환: 중복 생성 없음
- [ ] 변환 중 화면 이탈/앱 종료 후 재시도: 정상 동작

## 4. 곡 선택 캐러셀 & 준비 모달

- [ ] 세로 스와이프/셰브론(‹ ›)으로 포커스 곡 전환, 이웃 디스크가 위아래로 잘려 보임
- [ ] 포커스 디스크 뒤에 사각형 아티팩트 없음 (원형으로 깔끔)
- [ ] 페이지 dots가 실제 곡 수를 반영
- [ ] 포커스 디스크 탭 → 준비 모달, iOS 화면 안에 수납 (스크롤 없이 START 보임)
- [ ] 준비 모달: 난이도 5카드(천국/쉬움/보통/어려움/지옥, 색·아이콘·Lv), 배속 6칩(x0.5–x2.0)
- [ ] **레인 수는 난이도 고정** — 카드에 4/4/5/6/7 표기, 사용자가 못 바꿈
- [ ] START → 게임 진입 / ✕·스크림 탭 → 닫힘

## 5. 게임플레이 — 핵심 손맛 ★

곡 하나로 **보통** 먼저, 그다음 **천국**과 **지옥**.

- [ ] 원근 하이웨이: 하단이 가로로 넓고 상단 중앙으로 수렴, 핑크/시안 네온 레인 엣지
- [ ] 좌상단 HEALTH 링(체력 100%면 링이 꽉 참), 우상단 SCORE 링(점수+콤보) — 둘 다 상단
- [ ] 배속 버튼 없음, 우상단 일시정지 버튼만 존재
- [ ] 노트가 **박자에 맞게** 내려옴 — 리셉터 도달 시점 = 실제 비트 (어긋나면 방향/ms 보고)
- [ ] 글로시 노트: 흰 중앙 대시 + 광택, 리셉터 패드는 레인 폭에 가깝게 넓음
- [ ] 탭 판정: 정타 PERFECT, 살짝 어긋나면 GREAT/GOOD, 무시하면 MISS + 콤보 리셋
- [ ] 판정 표시 + 그 아래 회색 콤보 숫자 가독성
- [ ] 히트 성공 시 리셉터에서 위로 올라가는 그라데이션 불빛 + 원형 리플 (옆 레인 절반까지만 번짐, 레인 색과 어울림)
- [ ] 드래그 리본: 누르고 유지 → 점수 틱 증가; 이동 리본은 손가락 따라 추적
- [ ] **드래그 중간에 손 뗌/이탈 → 남은 리본 회색화 + 이후 점수 없음 + 콤보 리셋** (핵심 규칙)
- [ ] **동시노트는 항상 왼손/오른손 영역에 하나씩** (예: 6레인 → [1-3]+[4-6]) — 같은 손 영역에 둘 다 없음
- [ ] 천국: 널널 / 지옥: 빽빽 + 동시노트 + 드래그 — 난이도 격차 체감
- [ ] **지옥 밀도**: 빠른 곡에서 인트로 이후에도 밀도 유지 (초반만 빽빽하고 급감하지 않음)
- [ ] (실기기) 햅틱: PERFECT 묵직, GREAT/GOOD 가벼움, 드래그 브레이크 경고 진동
- [ ] (실기기) 3–4분 곡 풀플레이 중 프레임 드랍/발열/오디오 끊김 없음

## 6. 일시정지 / 중단

- [ ] 일시정지 버튼 → 음악+노트 즉시 정지, 오버레이 (계속하기/다시하기/나가기)
- [ ] 계속하기 → 3-2-1 카운트다운 후 **정확히 멈춘 지점부터** 재개 (판정 어긋남 없어야 함)
- [ ] 홈으로 나갔다 복귀 → 자동 일시정지 상태
- [ ] 플레이 중 전화/알람 수신 (실기기) → 자동 일시정지, 복귀 정상
- [ ] 다시하기 → 처음부터 재시작; 나가기 → 곡 선택 복귀

## 7. 결과 화면

- [ ] 곡 종료 → 점수, 최대 콤보, 판정 집계 (퍼펙트/그레이트/굿/미스) 표시
- [ ] 합계 검산: 판정 수 합 = 총 노트 수 (드래그는 헤드 1개 기준)
- [ ] "다시하기" / "곡 선택" 버튼 동작
- [ ] 같은 난이도 재플레이 후 점수 기록 유지 (ScoreRecord 저장)

## 8. 삭제 & 데이터

- [ ] 곡 선택에서 포커스 디스크 **길게 누름** → 삭제 확인 다이얼로그(빨강 border/trash 아이콘, 삭제/취소)
- [ ] 삭제 → 항목 + 비트맵 + 점수 + 오디오 파일 사라짐, 크래시 없음 (cascade 확인)
- [ ] 마지막/유일 곡 삭제 → 빈 상태로 깔끔히 전환
- [ ] 삭제 후 앱 재시작: 삭제 상태 유지
- [ ] 트랙 여러 개 (5개+) 상태에서 캐러셀 스와이프/라벨 정상

## 9. 엣지 케이스

- [ ] 아주 짧은 음원 (10초 미만): 변환/플레이 정상 or 합리적 처리
- [ ] 조용한 곡 (어쿠스틱/피아노): 노트가 너무 적거나 이상하지 않은지
- [ ] 무음 구간 긴 곡: 무음 구간에 노트 없음
- [ ] 저장공간 여유 없는 기기 (선택): 가져오기 실패 시 에러 메시지

---

**보고 요령**: 실패 항목은 `곡 이름 + 난이도 + 증상 + (가능하면) 타이밍 어긋남 방향(빠름/느림)`.
판정 윈도우·스크롤 속도·난이도 밀도/화음/드래그 정책은 상수로 모여 있어
(`JudgmentEngine.swift`, `DifficultyProfile.swift`, `MIRModels.swift`의 `DifficultyLayerPolicy`)
체감 기반 튜닝 즉시 가능.
